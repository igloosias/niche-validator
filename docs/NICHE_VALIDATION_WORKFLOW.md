# Complete Niche & Product Validation Workflow
## Automated + Manual Hybrid Approach for Shopify Dropshipping

---

## Overview

This workflow combines **automated data collection** with **manual verification** to give you a complete picture before investing in a niche. No tool or API gives you the full picture - this workflow bridges that gap.

**Time Required:** 3-5 days per niche (can be reduced to 1-2 days with practice)

---

## STAGE 1: Niche Discovery & Initial Filter

**Objective:** Go from infinite possibilities to a manageable list of viable niches

**Time:** 1-2 hours per session

---

### Step 1.1: Generate Niche Ideas

**Automated Sources:**

| Source | What It Shows | URL |
|--------|--------------|-----|
| Google Trends | Rising searches | trends.google.com |
| TikTok Trending | Viral products | tiktok.com/discover |
| Amazon New Releases | Hot categories | amazon.com/gp/new-releases |
| AliExpress Best Sellers | Top products | aliexpress.com/best-sellers |
| Reddit | Community interests | reddit.com |

**Process:**
```
1. Open Google Trends "Year in Search"
2. Check TikTok trending categories
3. Browse Amazon "Hot New Releases"
4. Note recurring themes across sources
```

**Output:** List of 20-30 potential niches

---

**Apply these elimination criteria IMMEDIATELY:**


**Output:** Filtered list of 10-15 niches

## STAGE 2: Niche Viability Validation

**Objective:** Score each remaining niche with data-driven metrics

**Time:** 30-60 minutes per niche

---

### Step 2.1: Automated Data Collection

**Use this data collection template:**

```
NICHE: [Insert Niche Name]
DATE: [Today's Date]
ANALYST: [Your Name]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**A. SEARCH DEMAND DATA**

| Metric | Tool | What to Record |
|--------|------|----------------|
| Monthly Searches | Google Trends | Interest score (0-100) |
| Trend Direction | Google Trends | Rising/Stable/Declining |
| Year-over-Year Growth | Google Trends | % change |
| Seasonality | Google Trends | Any peaks/troughs |
| Related Queries | Google Trends | List top 10 |

**How to Check:**
```
1. Go to Google Trends
2. Enter your niche keyword
3. Set timeframe: "Past 12 months"
4. Set location: Your target market (US/UK)
5. Record: Interest score, trend direction, related queries
```

**B. COMPETITION DATA**

| Metric | Tool | What to Record |
|--------|------|----------------|
| Amazon Best Sellers | Amazon.com | Number of products |
| Top Seller Reviews | Amazon.com | Avg review count |
| Review Growth | Keepa/Jungle Scout | % monthly growth |
| Price Range | Amazon.com | Min/Max prices |
| Keyword Difficulty | SEMrush/Ahrefs | KD score |
| CPC Estimate | Google Keyword Planner | Cost per click |

**How to Check:**
```
1. Amazon: Search niche, note # of results, click top 5, record reviews
2. Keepa: Enter top products, check review growth chart
3. SEMrush: Enter main keyword, note "Keyword Difficulty" score
4. Google Keyword Planner: Note suggested bid
```

**C. SUPPLIER AVAILABILITY**

| Metric | Tool | What to Record |
|--------|------|----------------|
| Supplier Count | AliExpress | Number of sellers |
| Avg Product Cost | AliExpress | Typical price point |
| Avg Supplier Rating | AliExpress | Out of 5 stars |
| Avg Shipping Time | AliExpress | Days to US |
| Stock Availability | AliExpress | In stock % |

**How to Check:**
```
1. AliExpress: Search niche, note # of suppliers
2. Filter: "Orders" to see best sellers
3. Click top 5 suppliers, record their ratings
4. Note typical product costs and shipping times
```

**D. SOCIAL SIGNALS**

| Metric | Tool | What to Record |
|--------|------|----------------|
| Instagram Posts | Instagram | Hashtag post count |
| TikTok Videos | TikTok | # of videos, views |
| Reddit Mentions | Reddit | Discussion activity |
| YouTube Videos | YouTube | Search results count |
| Pinterest Pins | Pinterest | Monthly impressions |

| Score | Tier | Action |

## Quick Reference: Validation Checklist

```
□ Niche has search demand (Google Trends)
□ Competition is manageable (Top sellers < 1000 reviews)
□ Products can be sourced profitably (cost < 30% of selling price)
□ Suppliers are reliable (4.5+ rating, responsive)
□ Social proof exists (TikTok/Instagram activity)
□ No legal/IP issues (Trademark check)
□ Can create marketing content (10+ content ideas)
□ Test ads get engagement (Before full launch)
□ Samples pass quality check (Before bulk order)
□ Backup suppliers identified (Insurance)
```

---

**This workflow combines data-driven scoring with manual verification. The automated parts give you efficiency and scale; the manual parts give you confidence and reduce risk. Neither alone is sufficient.**
